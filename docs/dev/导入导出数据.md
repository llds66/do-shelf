# DoShelf 导入导出数据计划

只记录后续待实现阶段，不再列出已完成阶段。

## 导入

### 第二阶段：合并导入

目标：

- 保留当前本地数据
- 将导入数据按规则并入本地数据

需要实现：

- 分类去重
- 书签按 `normalizedUrl` 去重
- 分类与书签关系去重
- 导入过程中的 id 映射
- 合并结果预览或结果提示

### 第三阶段：按需导入

目标：

- 支持只导入部分数据

需要实现：

- 导入后先展示预览
- 支持只导入部分分类
- 支持只导入部分书签
- 支持选择性保留分类与书签关系
